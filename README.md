# Snowbreak Auto CDK Redeemer

这是一个自动领取 **Snowbreak** CDK 的脚本，支持 Windows 运行。

## 🚀 功能特点
- 自动提交 CDK 兑换码
- 免去手动输入的繁琐步骤
- 支持 Windows 可执行文件（.exe）

## 🔧 使用方法
1. 下载 `cdk_redeem.exe` 并解压。
2. **必须以管理员身份运行**。
3. **目前仅支持 2560 分辨率**，游戏内分辨率无关。
4. 在游戏主界面运行即可。
